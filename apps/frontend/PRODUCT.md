# Product

## Register

product

## Users

Software engineers, product managers, designers, and other tech candidates preparing for high-stakes technical (DSA, System Design) and behavioral interviews. They need a realistic, high-fidelity simulation that mirrors the pressure and structures of actual top-tier company loops.

## Product Purpose

A real-time AI interview simulator that replicates the interview process of elite companies. It provides interactive voice-based chat, Monaco-powered live coding (DSA), and Excalidraw-powered system design boards, culminating in rigorous multidimensional scoring and feedback.

## Brand Personality

- **Focused:** A minimal, dark-mode-first environment that eliminates visual noise to let the user concentrate on the interview.
- **Elite:** Premium typography (serif/sans pairing), sharp high-contrast line borders, and editorial framing that feels like a professional terminal or modern editorial document.
- **Supportive:** Clear progress indicators, reassuring and professional microcopy, and intuitive control patterns that reduce user anxiety.

## Anti-references

- **SaaS Monoculture:** Avoid generic bright purple/blue gradients, thick drop shadows, and nested glassmorphism cards.
- **Default Browser Forms:** Avoid grey-on-grey low contrast text fields or generic borderless input blocks.
- **Over-stimulating motion:** No bouncy animations or excessive entrance transitions that distract from the interview.

## Design Principles

1.  **Editorial Frame:** Treat the layout as a structured, framed canvas (using corner ticks and hairline dividers) rather than a series of floating cards.
2.  **Contrast as Hierarchy:** Maintain extremely high ink contrast (minimum 4.5:1) and use weight/sizing axes instead of low-contrast gray text to convey text importance.
3.  **Adaptive Weighting:** Align the UI's look and feel with the selected interview's seriousness and character (e.g. challenging vs. supportive).

## Accessibility & Inclusion

- Strict compliance with WCAG AA contrast ratios (body text >= 4.5:1, display >= 3:1).
- First-class support for `prefers-reduced-motion` using instant or subtle crossfade overrides.
- Keyboard navigation and clear focus states for critical session control triggers.
